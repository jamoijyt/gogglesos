Features

What's inside

Goggles OS starts from the official Kubuntu 26.04 LTS release and adds what a PC VR player needs, so you get Ubuntu's long-term support and KDE Plasma underneath.

VR

  • Steam with steam-devices rules for Valve Index, HTC Vive, Quest and controllers
  • Install SteamVR: opens Steam's installer in one click
  • Goggles VR Setup: gives SteamVR's compositor the priority it needs for async reprojection

Graphics

  • NVIDIA 580 with prebuilt, Secure Boot-signed modules: GTX 900 to RTX 40, including the GTX 1080
  • Mesa and Vulkan (64- and 32-bit) for AMD and Intel
  • NVIDIA kernel mode-setting switched on for SteamVR direct mode and Wayland

Performance

  • Stock Ubuntu kernel with full preemption (preempt=full threadirqs)
  • SteamOS-style tuning: large max_map_count, no split-lock penalty, low swappiness
  • GameMode, MangoHud and GOverlay

Gaming & apps

  • Proton tools: ProtonUp-Qt (for Proton-GE) and Protontricks
  • OBS Studio and Discord preinstalled
  • Flathub enabled in Discover

Desktop

  • Glass (default) or Lite mode; switch later with Goggles Appearance
  • Frosted-glass taskbar and popups, Goggles Dark colours, rounded corners
  • Windows 10-style start menu with Play and Create & Share tiles
  • Papirus-Dark icons with green folders, green lock screen

Installer & safety

  • Calamares installer with a Glass/Lite Appearance step
  • Keeps Kubuntu's Secure Boot chain
  • The build pins third-party tools by checksum and fails if file ownership or permissions are unsafe
  • VMware guest tools included (screen resize, clipboard)
  • Goggles Update brings new Goggles OS changes without reinstalling

Get Goggles OS

Goggles OS comes in three editions. They're the same system with different graphics drivers, so pick the one that matches your GPU. The first public ISOs are coming soon; until then you can build any edition yourself.

Install from USB

  1. Check the download

    Compare the ISO's SHA-256 with the .sha256 file from the release. In PowerShell:

    Get-FileHash .\gogglesos-26.04-nvidia-amd64.iso -Algorithm SHA256

  2. Write it to a USB stick

    Use Rufus (choose DD Image mode when asked) or balenaEtcher. This erases the stick.

  3. Boot it

    Restart and open your PC's boot menu (usually F11, F12 or F8). Secure Boot can stay on. Choose Try Goggles OS to test it without changing anything, or Install Goggles OS.

  4. Install alongside Windows (optional)

    Install to a separate drive, or shrink a partition in Windows' Disk Management first and use Manual partitioning in the installer. Turn off Windows Fast Startup if you'll share a drive. Back up important files before partitioning.

  5. After installing

    Open Install SteamVR from the start menu, launch SteamVR once, then run Goggles VR Setup.

Goggles OS is in early development. Test in a virtual machine, or keep backups, before installing it on a PC you rely on.

Build

Build it yourself

The build remasters the official Kubuntu ISO: it unpacks the live system, customises it in a chroot, and repacks a new ISO that keeps Kubuntu's Secure Boot chain, live session and installer.

What you need

A Linux build environment

  • Ubuntu 26.04: a real install or WSL2 on Windows
  • Root access (the build uses chroot)
  • Internet access for packages

Space and memory

  • About 15 GB for the unpacked system (inside WSL)
  • About 15 GB for the base and output ISOs (default D:\GogglesOS)
  • On a 16 GB PC, close other apps during compression

Steps

  1. Windows only: install Ubuntu in WSL

    wsl --install -d Ubuntu

    Consider moving WSL to a big drive: wsl --manage Ubuntu --move D:\WSL\Ubuntu

  2. Get the source and the build tools

    git clone https://github.com/jamoijyt/gogglesos.git
cd gogglesos
sudo apt install xorriso squashfs-tools imagemagick webp

  3. Check the settings

    Open config.sh to change where the ISOs go (CACHE_DIR, OUTPUT_DIR), the package list and the GPU variant.

  4. Build

    Pick your options and copy the command:

    Graphics
    Build type 
    sudo ./build.sh

    The first build downloads the Kubuntu ISO and takes about an hour. After a build, wsl --shutdown gives WSL's memory back to Windows.

Build options

OptionWhat it does
GPU_VARIANT=amdLeave out the NVIDIA driver for a smaller ISO (the default nvidia ISO also works on AMD)
NVIDIA_BRANCH=580-openNVIDIA open kernel modules for RTX 50-series (drops GTX 10-series support)
RESUME=1Re-run customisation on the already unpacked system (after a failed build)
REUSE_ROOTFS=1Only repack the existing system into a new ISO
SQUASH_CPUS, SQUASH_MEMLimit compression threads and memory (defaults 6 and 1G)

Test in a virtual machine

On Windows with VMware Workstation, this creates a UEFI + Secure Boot VM with 3D acceleration (4 CPUs, 6 GB RAM, 64 GB disk) and boots the ISO:

.\vmware-test-vm.ps1

Run it again after each build to load the new ISO, or add -Recreate for a blank disk. hyperv-test-vm.ps1 does the same with Hyper-V (slower, no GPU acceleration), and test-iso.sh runs a QEMU boot test on Linux.
