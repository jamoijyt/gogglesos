# Hands

The low-poly hands from [Godot XR Tools](https://github.com/GodotVR/godot-xr-tools)
(`addons/godot-xr-tools/hands`, commit 6c6189b): models and textures by DigitalN8m4r3, CC0 (see
LICENSE.md). The `.res` files are XR Tools' open ("Grip 5") and closed ("Grip") poses, read by
hands.gd; textures converted to JPEG.
