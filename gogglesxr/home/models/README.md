# Goggles Home models

Everything here is CC0 (public domain). furniture.gd's catalogue says which file each thing uses.

| Folder | What | From |
|---|---|---|
| `ph/` | the detailed, textured furniture and decorations (57 models) | [Poly Haven](https://polyhaven.com), taken from the 1k/2k copies in [ezEngine/store-sample](https://github.com/ezEngine/store-sample) (`PolyHaven/`, commit ee6100b). The heaviest and oddly scaled ones were left out, and the textures were made smaller (1024 px; 512 px for small things) |
| `*.glb` | beds, desks, lamps, rugs, TVs, radio and a few more (22 models) | Kenney's [Furniture Kit](https://kenney.nl/assets/furniture-kit) 2.0, from [RetroDECK/RetroQUEST](https://github.com/RetroDECK/RetroQUEST) (commit dfa19a5), unchanged; see LICENSE.txt |
| `toys/` | RC cars and the cone, arcade machines, cube pets, blasters and the target | Kenney's Toy Car Kit, Mini Arcade, Cube Pets and Blaster Kit, from [series-ai/jam-ready-assets](https://github.com/series-ai/jam-ready-assets); each kit's colour map (`Textures/colormap.png`) is packed into its models. Licences: `toys/LICENSE-*.txt` |

Balls, blocks, balloons, posters, frames, the marker, the RC remote, the hoop, the wall clock and
the neon signs are made in code (gadgets.gd), as are the house itself (room.gd) and the VHS
tapes, player and box (game_shelf.gd).
