# Dashboard sounds

From Kenney's "UI Audio" pack (https://kenney.nl/assets/ui-audio), CC0 (public domain): see
LICENSE.txt. Taken from the Godot-ready copy at https://github.com/Calinou/kenney-ui-audio
(commit 8c3d81b), mixed down to mono and levelled to -3 dB peak.

| File       | Original       | Played when                                   |
|------------|----------------|-----------------------------------------------|
| hover.wav  | rollover5.wav  | the laser moves onto a button (quietly)        |
| click.wav  | click2.wav     | a button is pressed                           |
| toggle.wav | switch11.wav   | a switch or choice changes                    |
| swipe.wav  | rollover4.wav  | the dashboard moves to another panel          |
| open.wav   | rollover6.wav  | the dashboard opens (lower pitch: closes)     |
| key.wav    | click5.wav     | a key of the virtual keyboard                 |
| grab.wav   | switch28.wav   | a floating screen is picked up or put down    |
