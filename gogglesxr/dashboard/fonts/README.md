# Dashboard fonts

The same fonts as the Goggles OS website, Latin subset, from Fontsource (npm `@fontsource/inter`
5.2.8 and `@fontsource/outfit` 5.3.0). Both are under the SIL Open Font License 1.1: see the
OFL files here.

- Outfit 500 and 600: titles, the clock, panel names
- Inter 400 and 600: everything else

Characters these files don't have (arrows, symbols, other alphabets) come from the system's
fonts (Noto Sans) through a fallback.
